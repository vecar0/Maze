# UI 디자인 — 게임 화면과 같은 세계로 (v2.2)

## 문제
게임 화면은 도트 판타지 던전인데, 그 바깥의 UI(버튼·상태줄·알림·제목·결과)는
시스템 고딕 + 둥근 알약 버튼 + 평평한 회색 상자라서 **일반 웹앱처럼 보인다.** 둘이 따로 논다.

## 방향: "던전 벽에서 깎아 낸 돌판"
UI 조각 하나하나가 미궁의 돌벽에서 떼어 낸 판처럼 보이게 한다.
게임 속 오브젝트 강조색(주울 수 있는 것 = 금색 테두리, 위험 = 붉은색)을 UI에도 같은 뜻으로 쓴다.

### 글꼴
- **갈무리** (한글 도트 글꼴, OFL) — 게임 그림과 같은 '픽셀' 결.
  - 갈무리14: 제목·배너·결과 (15px의 2·3배 = 30·45px)
  - 갈무리11 / 11 Bold: 본문·버튼·알림 (12px · 24px)
  - 갈무리9: 캔버스 안 작은 글자 (10px)
- 도트 글꼴은 기준 크기의 **정수배에서만 선명**하므로 모든 글자 크기를 정수배로, 노트북 확대(zoom)도 정수로.
- 게임에 쓰는 글자만 남겨 파일에 내장 (4종 53KB) — 부스 노트북이 오프라인이어도 동작.

### 모양
- **둥근 모서리 없음.** 모서리는 2px 계단으로 깎는다 (도트 그림의 모서리처럼).
- 판·버튼 테두리: 2px 그늘 윤곽선 + 안쪽 2px 밝은 면(위·왼쪽) / 그늘 면(아래·오른쪽) — 픽셀 베벨.
- 행동 버튼: 원 → **계단 팔각형 룬석**. 상황 버튼(큰 것)은 금 테두리가 맥박.
- 그림자는 흐림 없이 2~3px 단단한 그림자만.
- 아이콘: 🔊·⛶ 같은 이모지 대신 **도트 아이콘**(SVG 픽셀). 결과 화면 통계엔 게임 스프라이트(하트·화살·구덩이·미끼·목재)를 그대로.

### 움직임
- 한 군데만: **도입 장면 글자가 한 글자씩 타자기처럼** 나온다 (옛 게임 대사창). 누르면 즉시 전체 표시 → 다음.
- 시작 버튼 옆 ▶ 가 계단식(steps)으로 깜빡 — 선택 커서.
- `prefers-reduced-motion` 이면 둘 다 끈다.

### 하지 않는 것
- 그라데이션 장식, 흐린 그림자, 둥근 카드, 이모지, 시스템 글꼴.
- 레이아웃·크기는 그대로 둔다 (손가락 크기 44px+, 버튼 간격, 폰/노트북 배치 검수 통과 상태 유지).
